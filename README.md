# Student Task Manager

A Java-based command-line application for managing student tasks efficiently.

## Features

- Add tasks
- View all tasks
- Update tasks
- Delete individual tasks
- Clear all tasks
- Mark tasks as completed
- Reopen completed tasks
- Set task priority
- Set task due date
- Search tasks
- Filter tasks by status
- Filter tasks by priority
- Sort tasks by priority
- Sort tasks by due date
- Task statistics
- Overdue task detection
- Input validation
- File-based data persistence

## Technologies Used

- Java
- Git
- GitHub
- GitHub Actions
- ArrayList
- File Handling
- Java OOP
